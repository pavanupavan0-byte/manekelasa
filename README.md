
# Mane-Kelsa 🛠️📱

Android App Development using GenAI - Hyper Local Self-Employment Platform

## 📌 Project Overview

Mane-Kelsa is a hyper-local work directory Android application designed to connect domestic workers and local residents.  
Workers can list their skills, availability, and contact information, while residents can easily find nearby workers for short-term or daily tasks.

The application helps reduce unemployment gaps and promotes local self-employment opportunities.

---

## 🚀 Features

- Worker profile creation
- Daily availability status
- One-tap direct calling feature
- Local worker listing
- Ratings and trust system
- Real-time availability updates
- Kannada-friendly user interface

---

## 🛠️ Technologies Used

- Android Studio
- Java / Kotlin
- XML
- Firebase Realtime Database
- Firebase Authentication
- Material Design Components
- GenAI APIs
