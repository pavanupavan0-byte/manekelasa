# Jal-Sanchay Tracker 🌧️💧

Android App Development using GenAI - Rainwater Harvesting Tracker

## 📌 Project Overview

Jal-Sanchay Tracker is an Android application designed to help households monitor and measure the effectiveness of rainwater harvesting systems.  
The application calculates water savings based on roof area and rainfall data and promotes sustainable water conservation habits.

---

## 🚀 Features

- Rainwater harvesting calculation
- Water savings dashboard
- Tank fill progress visualization
- Historical rainfall data storage
- Monthly water saving reports
- Water conservation tips
- User-friendly Android UI

---

## 🛠️ Technologies Used

- Android Studio
- Java / Kotlin
- XML
- Firebase / Room Database
- GenAI APIs
- Material Design Components

---

## 📐 Formula Used

Water Saved = Area × Rainfall × 0.0929 × Runoff Coefficient
